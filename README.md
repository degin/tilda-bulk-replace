# tilda-bulk-replace

Скилл (формат Hermes / Claude) для массовой замены одного значения на десятках страниц Tilda через MCP: выгрузка, генератор заданий, dry-run, запись, сверка остатков. Python 3, только stdlib.

Обкатан на проекте из 18 страниц: 138 замен, 0 ошибок записи, повторная выгрузка без остатков.

## Установка

Скопируйте папку в каталог скиллов вашего агента (или клонируйте репозиторий туда) под именем `tilda-bulk-replace`. Токен Tilda MCP передаётся переменной окружения `TILDA_MCP_TOKEN`, проект задаётся `--project` или `TILDA_PROJECT_ID`.

## Содержимое

- `SKILL.md` — порядок работы и ловушки.
- `scripts/` — `tilda_blocks.py`, `tilda_patch.py`, `gen.py`, `scan.py`.
- `examples/` — таблица замен, список страниц, пример задания.

Скрипты ничего не публикуют: запись в Tilda не публикует страницы, это делает владелец сайта.
